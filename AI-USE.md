# How we used AI

The 2026 Congressional App Challenge allows AI tools if "all AI usage is fully disclosed in the submission materials". This file is that disclosure for First ID.

- The **summary** below says which tools we used and for what.
- The **log** has one row for every piece of work an AI tool wrote or substantially changed: the date, what it was (with the files), the tool, and who on the team reviewed it and what they changed. Bracketed entries in the last column are still waiting for that teammate to fill in.
- Commits written by Claude say "AI-generated by Claude" in the subject or end with a `Co-Authored-By: Claude` line, so `git log` matches this file.

We add a row whenever an AI tool writes or substantially changes something.

## Summary

- **Tools:** Anthropic Claude, the only AI tool in the log below. We used it for research, the starter scaffold, the first draft of the rules file and the Spanish, the screens and the site's redesigns, copy passes, and code review.
- **The app itself uses no AI.** Plans come from a deterministic planner over the rules file. The same inputs always give the same plan.
- **Rules and AI:** Claude drafted the rules in `data/rules.json` from its research notes. A rule only counts as verified when a teammate has checked it against the primary source linked next to it; until then the app shows it as "call ahead". As of this update, 0 of the 11 rules are marked verified.
